# M5StopWatch FMO 刷机教程

> 适用项目：`m5stopwatch-fmo`
> 适用固件：
> 1. **M5StopWatch 手表固件**（`watch/fwmo_main/fwmo_main.ino`）
> 2. **ESP-NOW 接收端**（`receiver/fmo_tx_espnow/fmo_tx_espnow.ino`，ESP32-S3 + PCM5102A DAC 模块）
> 刷机方式：Arduino IDE 图形化操作（本机已验证环境：m5stack:esp32 3.3.8 / LVGL 8.4.0）
> 最后更新：2026-08-18

---

## 0. 刷机前要准备什么

### 硬件

| 硬件 | 用途 |
|------|------|
| M5StopWatch C152（ESP32-S3）| 手表本体 |
| USB-C 数据线 | 给手表烧录（尽量用能传数据的线，不要用纯充电线）|
| ESP32-S3 开发板 | ESP-NOW 接收端 |
| PCM5102A DAC 模块 | 接收端音频输出（你已改成该模块）|
| 0.96" SSD1306 OLED（可选）| 接收端状态显示 |
| 杜邦线 / 电阻 / 电位器 | 接收端接线与分压 |

### 软件

- **Arduino IDE**（1.8.x 或 2.x 均可；烧录字库文件系统建议用 1.8.x + 插件，见 4.4 节）
- **M5Stack ESP32 板卡包**（`m5stack:esp32`，推荐 3.3.8）
- 项目自带的环境检查：本机已安装 LVGL 8.4.0、M5Unified、M5GFX、ArduinoJson、Adafruit SSD1306 等库。

---

## 1. 安装 Arduino IDE

1. 到 <https://www.arduino.cc/en/software> 下载 Arduino IDE 并安装。
2. 如果之前装过，建议升级到 2.x；但 4.4 节的“文件系统上传”插件目前只稳定支持 1.8.x，二选一即可：
   - 只用 **1.8.x**：图形化上传字库最省事。
   - 用 **2.x**：烧固件没问题，字库用 4.4 节中的命令行/替代方式。

---

## 2. 安装 M5Stack ESP32 板卡包

1. 打开 Arduino IDE。
2. 菜单 **Arduino IDE → 设置**（macOS）或 **文件 → 首选项**（Windows）。
3. 在 **附加开发板管理器网址** 中添加：

   ```
   https://m5stack.oss-cn-shenzhen.aliyuncs.com/resource/arduino/package_m5stack_index.json
   ```

   如果访问慢，可加官方源：

   ```
   https://static-cdn.m5stack.com/resource/arduino/package_m5stack_index.json
   ```

4. 打开 **工具 → 开发板 → 开发板管理器**。
5. 搜索 `m5stack`，安装 **M5Stack ESP32 Arduino**（本机使用 **3.3.8**）。

> 本机已安装 `m5stack:esp32 3.3.8`，无需重复安装。
> 注意：本项目 README 指定用 M5Stack 官方板卡包，不要只用 Espressif 的 `esp32` 包，否则可能没有 `M5StopWatch` 板卡选项。

---

## 3. 安装所需库

打开 **工具 → 管理库**，搜索并安装：

| 库名 | 作者 | 用途 | 必装 |
|------|------|------|------|
| M5Unified | M5Stack | 手表硬件初始化（屏幕/按键/电池）| ✅ |
| M5GFX | M5Stack | 屏幕驱动（M5Unified 会依赖）| ✅ |
| LVGL | LVGL | 界面库（**请用 8.4.x**，本项目按 v8.4 编写）| ✅ |
| ArduinoJson | Benoit Blanchon | FMO JSON 事件解析 | ✅ |
| ESP32-A2DP | pschatzmann | 经典蓝牙音频（ESP32-S3 上自动禁用，可装可不装）| ⬜ |
| Adafruit GFX | Adafruit | ESP-NOW 接收端 OLED | ✅ |
| Adafruit SSD1306 | Adafruit | ESP-NOW 接收端 OLED | ✅ |

> ⚠️ **LVGL 版本很重要**：项目使用 LVGL **8.4.0**，不要装 LVGL 9.x，否则 API 不兼容。
> 项目里 `watch/fwmo_main/lv_conf.h` 是自定义配置，必须和 `fwmo_main.ino` 在同一目录；Arduino 编译时会自动使用同目录的 `lv_conf.h`。

## 4. 烧录 M5StopWatch 手表固件

### 4.1 打开工程

1. 用 Arduino IDE 打开：

   ```
   watch/fwmo_main/fwmo_main.ino
   ```

2. 打开后应能看到同目录下的 `fwmo_*.h`、`lv_conf.h`、`wicon.c` 等文件。

### 4.2 选择开发板和烧录参数

菜单 **工具** 下设置：

| 设置项 | 选择 |
|--------|------|
| 开发板 | **M5Stack Arduino → M5StopWatch** |
| Partition Scheme | **app3M_fat9M_16MB** |
| Flash Size | 16MB |
| Upload Speed | 921600（连不上再降到 115200）|
| USB CDC On Boot | Enabled（如果走原生 USB 且要串口监视器）|
| 端口 | M5StopWatch 对应的串口 |

> 如果列表里没有 `M5StopWatch`，说明板卡包不对或没装 M5Stack 官方包，回到第 2 节检查。
> 如果端口里看不到手表：
> - 换一根数据线；
> - 确认 USB-C 插紧；
> - 到“系统报告 → USB”看是否有设备；
> - 一般 M5StopWatch 不需要手动进 Boot 模式，插上就能识别。

### 4.3 编译并烧录固件

1. 点击 **→**（上传）按钮，或菜单 **项目 → 上传**。
2. 首次编译较慢，等待底部进度条走完。
3. 看到 `Connecting...` 后开始写入，写入完成后会自动复位运行。

> 如果一直卡在 `Connecting...`：
> - 按住手表侧键（或 B 键）再插 USB，出现写入进度后松手；
> - 或先按一下复位键再点上传；
> - 把 Upload Speed 降到 115200 再试。

### 4.4 烧录字库/呼号表（LittleFS，**必须做**）

固件本身不包含中文字库和呼号表，它们在 LittleFS 分区里。**只烧固件不烧字库，手表会显示“/font_hansan_24.bin 不存在”或中文乱码。**

字库需要写入的 2 个文件：

```
font_hansan_24.bin   # 中文字库（由 font_gen.py 生成）
callloc.bin          # 呼号→城市 离线表（由 gen_callloc.py 生成）
```

#### 方法 A（推荐）：Arduino IDE 1.8.x + ESP32FS 插件

1. 下载插件：<https://github.com/me-no-dev/arduino-esp32fs-plugin/releases>
2. 解压后，将 `ESP32FS` 文件夹放到 Arduino 安装目录的 `tools/ESP32FS/tool/` 下（macOS 通常是 `/Applications/Arduino IDE.app/Contents/Java/tools/`，Windows 是 `Arduino 安装目录/tools/`）。
3. 重启 Arduino IDE。
4. 在 `watch/fwmo_main` 文件夹里新建 `data` 文件夹：

   ```
   watch/fwmo_main/
     ├── fwmo_main.ino
     ├── ...
     ├── font_hansan_24.bin
     ├── callloc.bin
     └── data/                # 新建
         ├── font_hansan_24.bin   # 复制进去
         └── callloc.bin          # 复制进去
   ```

5. 确认开发板仍是 `M5StopWatch`、分区仍是 `app3M_fat9M_16MB`。
6. 菜单 **工具 → ESP32 Sketch Data Upload**。
7. 等待上传完成，串口会打印 LittleFS 烧录信息。

#### 方法 B：命令行（适合 2.x / 不想装插件）

项目里已有打包脚本 `watch/fwmo_main/fs_pack.py`，但它写的是 Windows 路径，Mac 上需要改成自己的 mklittlefs/esptool 路径后运行：

```bash
cd watch/fwmo_main
python3 fs_pack.py            # 生成 font_fs.bin
python3 fs_pack.py --flash    # 生成并烧录（脚本内串口需修改）
```

或者直接用 mklittlefs + esptool 把 `font_fs.bin` 写到 **0x610000**。

### 4.5 验证

1. 打开 **工具 → 串口监视器**，波特率 **115200**。
2. 重启手表，应看到：

   ```
   [字体] 头: bpp=... glyph=... bitmap=... rest=...
   [WiFi] 已连接! IP=...
   ```

3. 屏幕上应显示 FMO 主界面，中文呼号/台站正常显示。
4. 按 A+B 打开菜单，检查 WiFi、FMO Host 等配置。

## 5. 烧录 ESP-NOW 接收端（fmo_tx_espnow）

### 5.1 硬件接线（PCM5102 DAC 模块）

> 你已经把 DAC 改成 **PCM5102 模块**，按下面接线即可。

| PCM5102A | ESP32-S3 | 说明 |
|----------|----------|------|
| VIN | 3.3V | 供电 |
| GND | GND | 共地（同时接 FMO GND）|
| BCK | GPIO5 | I2S 位时钟 |
| LRCK | GPIO6 | I2S 帧时钟 |
| DIN | GPIO7 | I2S 数据 |
| SCK | GND | 内部生成 MCLK |
| OUTL | 分压网络 | → FMO AIN+ |
| GND  |        | → FMO AIN- |

其他信号：

| 信号 | ESP32-S3 | 说明 |
|------|----------|------|
| PTT | GPIO4 | → FMO NET PTT（发射时高）|
| LED | GPIO2 | 发射指示灯（串 330Ω 到 GND）|


**输出到 FMO 的分压**（PCM5102A 输出约 2.8Vpp，FMO AIN 需 ≤200mV）：

```
PCM5102A OUTL ──┬──[47kΩ]──┬──→ FMO AIN+
                └──[4.7kΩ]──┘
                     ↓ GND
```

如果声音偏大/削波，改用 **100kΩ:4.7kΩ**，或换成 100kΩ 电位器（①输入、②输出到 AIN+、③接地）现场调。

> ⚠️ 如果 DAC 模块输出带直流偏置（2V 左右），在分压前先串 **1µF 隔直电容**，否则可能削波失真。

### 5.2 打开工程并选择板卡

1. 用 Arduino IDE 打开：

   ```
   receiver/fmo_tx_espnow/fmo_tx_espnow.ino
   ```

2. 菜单 **工具** 下设置：

| 设置项 | 选择 |
|--------|------|
| 开发板 | **ESP32S3 Dev Module**（任意 ESP32-S3 开发板）|
| Flash Size | 按你板子实际容量选（4MB/8MB/16MB 都行，本固件很小）|
| Partition Scheme | 默认即可（不需要特殊分区）|
| USB CDC On Boot | Enabled（板子用原生 USB 口时必须有，否则串口无输出）|
| Upload Speed | 921600（连不上降到 115200）|
| 端口 | 接收端对应的串口 |

> 如果你用的是 M5Stack 板卡包，也可以选 M5Stack 下的 ESP32-S3 对应板型；核心要求是 **ESP32-S3**。

### 5.3 修改 WiFi 配置

打开 `receiver/fmo_tx_espnow/fmo_tx_espnow.ino`，修改为你自己的 WiFi：

```cpp
const char* WIFI_SSID = "你的WiFi名称";
const char* WIFI_PASS = "你的WiFi密码";
```

> ESP-NOW 配对依赖和手表在同一个 WiFi 环境，所以这里要填真实 WiFi。

### 5.4 编译上传

1. 点击 **→**（上传）。
2. 打开 **串口监视器**，波特率 **115200**。
3. 正常启动应看到：

   ```
   === FMO TX (ESP32-S3 + ESP-NOW + PCM5102A) v2 ===
   [OLED] OK
   [I2S] PCM5102A 就绪 (8kHz/16bit)
   [WiFi] 已连接! IP=... MAC=34:85:18:xx:xx:xx
   [ESPNow] MAC: 34:85:18:xx:xx:xx
   === 就绪：等待 StopWatch ESP-NOW 语音 ===
   ```

### 5.5 配对：把接收端 MAC 填进手表固件

1. 记下接收端串口打印的 **MAC 地址**（如 `34:85:18:12:34:56`）。
2. 打开手表固件里的：

   ```
   watch/fwmo_main/fwmo_mic_espnow.h
   ```

3. 找到并修改：

   ```cpp
   #define FMO_RX_MAC  "7C:4F:AD:2A:8D:00"   // ← 改成你的接收端 MAC
   ```

4. 重新编译上传手表固件（见第 4 节）。

### 5.6 验证

1. 手表按住 **A 键** 说话。
2. 接收端 OLED 应显示 `RX AUDIO`，电平条跳动，LED 亮。
3. FMO 应能收到上行语音，松开发射停止。

## 6. 常见问题（FAQ）

| 现象 | 原因/解决 |
|------|-----------|
| 电脑不识别手表/开发板 | 换数据线；装 CP210x/CH340 驱动；确认 USB 口 |
| 上传卡 `Connecting...` | 按住 BOOT/侧键插线；降 Upload Speed 到 115200 |
| 编译报 `lv_conf.h` 找不到 | LVGL 必须装 8.4.x；确认 `lv_conf.h` 在 `watch/fwmo_main` 目录 |
| 编译报 `LV_CONF_INCLUDE_SIMPLE` 未定义 | 在 `lv_conf.h` 顶部按注释定义，或改用 LVGL 8.4.0 原版库配置 |
| 烧完固件屏幕没中文/提示字库不存在 | 没烧 LittleFS；按 4.4 节烧 `font_hansan_24.bin` + `callloc.bin` |
| 上传文件系统后仍读不到文件 | 分区没选 `app3M_fat9M_16MB`；确认上传的是 `data/` 里的两个文件 |
| ESP-NOW 收不到音频 | 接收端 MAC 没配对；`FMO_RX_MAC` 大小写/格式错误；两端不在同一 WiFi |
| 接收端 OLED 不亮 | 检查 SDA=10 / SCL=11；确认模块地址是 0x3C；`Adafruit SSD1306` 已装 |
| DAC 无声 | 检查 XSMT 接 3.3V、FMT 接 GND；BCK/LRC/DIN 是否 GPIO5/6/7；分压后是否进 AIN+ |
| 声音发闷/削波 | PCM5102A 输出先串 1µF 隔直电容，再分压/电位器调低到 ≤200mV |
| PTT 不动作 | 检查 GPIO4 到 FMO NET PTT；共地 |

## 附：重新生成字库/呼号表

改了显示文字或呼号数据后，需要重新生成并烧录：

```bash
cd watch/fwmo_main
python3 font_gen.py    # 生成 font_hansan_24.bin
python3 gen_callloc.py # 生成 callloc.bin
python3 fs_pack.py     # 打包 font_fs.bin（Mac 需先改脚本里的工具路径）
```

然后按 4.4 节重新烧录 LittleFS。
