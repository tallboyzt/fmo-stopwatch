# M5StopWatch FMO 接收端设计文档

> 版本：2.0（ESP-NOW 方案，替代旧 UDP 方案）
> 日期：2026-08-18
> 项目：m5stopwatch-fmo

## 1. 系统架构

### 1.1 总体拓扑（同一 WiFi 局域网）

```
┌────────────────── WiFi 路由器 ──────────────────┐
│                                                  │
│   ┌──── FMO 盒子 (WiFi 设备) ────┐               │
│   │ · WebSocket 服务器          │               │
│   │ · AIN+/NET PTT 模拟接口     │               │
│   └───────┬─────────────────────┘               │
│           │ WebSocket (ws://<host>)              │
│   ┌───────▼─────────────────────┐   ┌──────────┐│
│   │      M5StopWatch (手表)      │   │ ESP32-S3  ││
│   │  · 接收：WebSocket          │   │ 接收端    ││
│   │  · 发射：ESP-NOW 麦克风     │──▶│ (ESP-NOW→ ││
│   └─────────────────────────────┘   │  DAC→FMO)││
│                                      └────┬─────┘│
│                                           │ 模拟音频+PTT
│                                   ┌──────▼─────┐│
│                                   │ FMO 盒子    ││
│                                   │ AIN+/NET PTT││
│                                   └─────────────┘│
└──────────────────────────────────────────────────┘
```

### 1.2 双向通联分工

| 方向 | 路径 | 说明 |
|------|------|------|
| **📥 接收** | FMO盒子 → WebSocket → 手表 | 音频流 + 呼号/台站/事件（JSON）|
| **📤 发射** | 手表 → ESP-NOW → 接收端 → 模拟音频/PTT → FMO盒子 | 麦克风语音上行 |

> **发射链路关键点**：ESP-NOW 点对点（低延迟、无服务器依赖），接收端接 PCM5102A DAC 输出到 FMO AIN+，GPIO4 控制 NET PTT（高有效）。

## 2. 发射协议（ESP-NOW）

### 2.1 数据包格式

每包 ≤250 字节：

```
[0]      PTT 标志（1=发射，0=停止）
[1:2]    序号（uint16 big-endian）
[3:243]  8bit 音频样本 ×240（240 样本 ≈ 31ms @ 7.66kHz）
```

- 手表实际采集速率 ≈ **7.66kHz**（32 包/s，I2S 时钟偏差）
- 接收端重采样 240→250 样本/包（25:24）→ 匹配 8kHz 播放
- PTT 控制包（3 字节）与音频包分开

### 2.2 链路参数

| 参数 | 值 |
|------|-----|
| WiFi | STA 模式（同路由器，同信道）|
| ESP-NOW | 点对点（手表→接收端 MAC）|
| 手表 FMO_RX_MAC | 接收端实测 MAC（如 7C:4F:AD:2A:8D:00）|
| 音频速率 | 32 包/s（手表侧）|
| 延迟 | ~150ms（缓冲 5 包 + DMA 3×256）|

## 3. 接收端设计（receiver/fmo_tx_espnow）

### 3.1 硬件连接

**GY-PCM5102 焊盘配置（必须）**：

| 焊盘 | 短接 | 含义 |
|------|------|------|
| H1L | L↔引脚 | FLT 正常滤波器 |
| H2L | L↔引脚 | DEMP 关闭去加重 |
| H3L | **H↔引脚** | XMT 取消静音（必须）|
| H4L | **L↔引脚** | FMT I2S 格式（必须）|
| SCK | 接地 | 内部时钟模式 |

**引脚连接**：

| 信号 | ESP32-S3 | 说明 |
|------|----------|------|
| DAC BCK | GPIO5 | I2S 位时钟 |
| DAC LCK | GPIO6 | I2S 帧时钟 |
| DAC DIN | GPIO7 | I2S 数据 |
| DAC VIN | 3.3V | 供电 |
| DAC GND | GND | 共地 |
| DAC OUT（3.5mm口或排针）| 电位器 → FMO AIN+ | 分压 ≤200mV |
| GPIO4 | FMO NET PTT | 高有效（发射时拉高）|
| GPIO2 | LED | 发射指示 |
| OLED SDA | GPIO10 | 状态显示 |
| OLED SCL | GPIO11 | 状态显示 |

**音频输出（→ FMO AIN）**：
- 优先用 DAC 板 3.5mm 口（自带 2.2µF 隔直 + 470Ω）
- 或排针 OUTL/OUTR 串 4.7µF 隔直电容
- 100kΩ 电位器分压（1/10 位置 ≈ 200mV），FMO AIN 上限 200mV
- AIN- 接地，ESP32 GND ↔ FMO GND 必须共地

### 3.2 软件架构

```
ESP-NOW 回调（onDataRecv）
  ├── PTT 检测 → GPIO4 拉高/拉低 + LED
  ├── 8bit 解包 → 噪声门（滞回+慢平滑）→ 重采样(240→250) → 16bit → 环形缓冲
  └── OLED 状态更新（电平/包数）

独立播放任务（playTask，core 1）
  ├── 从环形缓冲取数据 → I2S 写 PCM5102A
  └── 缓冲空 → 写 8ms 静音帧（保持连续）

主循环（loop）
  ├── PTT 超时释放（1s 无包）
  └── OLED 刷新（100ms）
```

### 3.3 关键算法

**噪声门（降噪）**：
```cpp
if (maxAbs < 5)        gate = 0.0;    // 背景静音
else if (maxAbs < 15)  gate = (maxAbs-5)/10.0*0.6;  // 低电平衰减
// 滞回：已静音时需 maxAbs>20 才恢复
if (gateSmooth < 0.05 && maxAbs < 20) gate = 0.0;
gateSmooth += (gate - gateSmooth) * 0.12;   // 慢平滑防 32Hz 调制
```

**重采样（速率匹配）**：
```cpp
// 发送端 7.66kHz(32包/s) → 播放 8kHz：每包 240→250 样本（25:24 线性插值）
int nOut = n * 25 / 24;
// 输出 j 对应输入 pos = j*24/25，线性插值
```

**环形缓冲 + 信号量**：5 包容量（150ms），吸收 ESP-NOW 抖动。

### 3.4 OLED 显示

```
┌──────────────────────┐
│ RX Ready     32/s    │ ← 状态 + 每秒收包数
│ ██▒▒▒▒▒▒▒▒▒▒        │ ← 音频电平条（12格）
│ pkt:1523   lv:56%   │ ← 总收包数 + 实时电平
└──────────────────────┘
```

## 4. 手表端发射设计（watch/fwmo_main）

### 4.1 采集链路

```
A键按住 → setTransmit(true)
  ├── 发送 PTT=1 控制包
  ├── 清空 RX DMA 积压（防旧声音打包）
  └── 丢弃前 3 包（按键噪声，~90ms）
→ readRx(480, 50ms) → 16bit→8bit 压缩 → ESP-NOW 发送
```

### 4.2 关键修复

| 问题 | 修复 |
|------|------|
| 按键瞬间杂音 | RX DMA 清空 + 前 3 包预热丢弃 |
| 包间隙（啾啾声）| readRx 超时 30→50ms（>31.3ms 实际读满耗时）|
| 台站不同步 | 每 30s 定时 getCurrent 刷新 |

## 7. 注意事项

1. **接收/发射独立**：接收走 WebSocket（TCP 可靠），发射走 ESP-NOW（实时低延迟）
2. **速率匹配**：手表 I2S 实际 7.66kHz，接收端重采样 25:24 匹配 8kHz 播放
3. **PTT 时序**：收到 PTT=1 拉高，1s 无包释放（防持续占网）
4. **FMO AIN 上限 200mV**：电位器从最小调起，避免削波
5. **共地必需**：ESP32 GND ↔ FMO GND 不共地会引入噪声
6. **降噪**：噪声门消除背景沙沙（滞回+慢平滑防周期调制）
